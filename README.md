# 72relay

Publie toutes les ~5 minutes un condensé (~300 octets) des tables live du
club 72Poker (Sihanoukville), lu par un petit écran-cube autonome.

- Source : API publique PokerAsiaManager du club
- Sortie : `poker.json` sur la branche `data` (un seul commit, réécrit)
- Consommateur : firmware smalltv-mod modifié (fork local d'Erwan)
